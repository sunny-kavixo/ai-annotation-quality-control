# V0.4 — annotation review dashboard

The QC engine now detects structural, image-boundary, and label-quality problems, but JSON alone is awkward for a human reviewer.

This milestone starts a reviewer-facing Streamlit prototype that consumes the **real exported QC report plus its source CSV**. It shows dataset/QC totals, label distribution, issue filtering, row-level annotation data, and optionally renders the selected bounding box over an uploaded source image.

## Why image upload is still manual

A browser dashboard cannot safely assume that paths such as `images/301.jpg` exist on the machine hosting the app. The first slice makes that boundary visible instead of pretending image resolution is solved.

The next exercise should determine a reliable dataset/image loading model, then add tests around the non-UI review data preparation before this milestone is considered complete.
